# 🧠 CodeBreaker

Logic • Deduction • Reasoning

A logic challenge inspired by an academic exercise.

The objective is simple: discover the secret number generated by the computer using reasoning, deduction and pattern analysis.

---

## 🎯 Objective

Break the code by identifying the hidden number through a sequence of attempts and logical clues.

Each guess brings new information, helping the player narrow down the possibilities until the correct answer is found.
